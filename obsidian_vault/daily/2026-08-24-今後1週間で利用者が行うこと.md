### 1. 毎営業日（自動＋簡単な確認）

- **自動実行を確認する**（何もしなくてよいが、初日〜数日は見ておく）：16:00に`kaizen ingest`、16:05に`kaizen predict run`がタスクスケジューラで自動実行されます
- **`reports/daily/YYYY-MM-DD.md`を読む**（当日分の選定結果・警告を確認）
- 気になる日があれば `python -m kaizen predict status` を実行し、直近のwin率・評価待ち件数・現行版数を確認する

### 2. 今週中に1回：hybrid選定を試す（5-2の実データ確認に必須）

自動選定（`auto_fallback`）だけでは確信度（`llm_confidence`）が記録されず、日次レポート§6.1「確信度キャリブレーション」が埋まりません。

1. `python -m kaizen predict run` の実行後、Claude Codeで **`/predict-daily`** を実行する
2. `python -m kaizen predict ingest` を実行して回答を取り込む
3. レポートが「Claude選定（hybrid）」表記に更新されることを確認する

### 3. 今週の日曜（推奨）：週次レビューを1回通す（5-3〜5-5・5-7の実データ確認に必須）

1. `python -m kaizen predict review weekly` を実行
2. Claude Codeで **`/predict-weekly`** を実行
3. `python -m kaizen predict review ingest` を実行 → 承認可否の目安（`[承認推奨]`／`[承認は時期尚早]`）が表示される
4. `reports/prediction/weekly/{週}.md` を読み、内容を吟味する
5. 納得すれば `python -m kaizen predict version approve <版数>` で承認（**必須ではない**。見送ってもよい）

これを1回通すと、累積損益・win率推移・確信度キャリブレーションの3種のチャートも自動生成されます（5-7の確認）。

### 4. 今週中に1回：知識ノートを試す（5-8の実データ確認）

1. `knowledge/` 配下に Markdown ファイルを作成（Frontmatterに`created_at`必須）
2. `python -m kaizen knowledge index` を実行
3. 次回の `/predict-daily` プロンプトに、そのノートの関連情報が反映されることを確認する
4. `python -m kaizen knowledge stale` で再確認期限の一覧表示も試す

### 5. 週の終わりに：運用状況の確認

- `python -m kaizen doctor` を実行し、`[NG]`が無いか確認
- `Get-ScheduledTask` でタスクスケジューラ2件の状態が `Ready` のままであることを確認
- もしPCがオフラインだった日があれば、翌営業日に手動で `python -m kaizen ingest` を1回実行して欠損を回復させる
