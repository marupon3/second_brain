# 「知識」vs「情報」ナレッジマネジメントの「教祖」が宗旨替え？

2017年2月11日土曜日
19:20
ナレッジマネジメントの「教祖」が宗旨替え？
往時のナレッジマネジメント・ブームの立役者、教祖と言えば、海外ではトーマス・H・ダベンポート教授でした。理論志向というよりはコンサルタントとしての立ち位置で様々な企業の事例を紹介し、例題に語らせるスタイルがいかにも米国流という印象でした。
その彼が最近出した本が、『Big data
＠Work』（直訳すると、現場で働くビッグデータ）、邦題『データ・アナリティクス3.0 ～ビッグデータ超先進企業の挑戦』（小林啓倫・訳、日経BP社）です。
驚きました。なぜなら、知識に比べたら情報はもちろん、データなどはさらに下位、低級なもの、とかつては位置づけられていたはず、という思い込みがあったからです。
「知識」vs「情報」については先に図解させていただいたので、「情報」vs「データ」の違いを考えてみると、大ざっぱですが、
+ （生）データは、事実そのもの、センサーや入力機器が捉えたデジタル数値や記号列
+ 情報は、そのデータの位置づけ、意味づけ（解釈）の標準が添付されていたり、データ生成が繰り返し生じるパターンをとらえたもの
のように、互いに区別することができます。
知識管理の重要性を強調していたダベンポート教授がなぜ、データに「降りてきた」のか？　皆様には、書籍を参照して是非ご自身で考えていただきたいところですが、私見ながら、いくつか仮説を立ててみました。
+ 10数年前のナレッジマネジメント・ブームの時には、計算パワーやネットワーク容量が小さくて、知識管理や編集をサポートするITが実装できなかった。
+ だから、多くのモデルや知見が実データを使って検証できる状況ではなかった。
+ ビッグデータ時代の今日、日々入ってくる膨大な外部データやAPIなどの資源によって、意見を醸成する以前に、あるいは明白な選択肢から決断するための重要な事実を発見、発掘することが可能になった。このため知識そのものより、その原料、新鮮な現場の生データの重要性が増した。
+ ナレッジマネジメント・ブームの際には、組織内部の改革に重きを置いたが、なかなか自ら変われない企業体そのものよりも、内外のデータの入出力から変えるほうが勝算が高いと判断した。
上記書籍でダベンポート教授は、ビッグデータの恩恵として、
+ （1）コストの削減
+ （2）意思決定の改善
+ （3）製品・サービスの改善
の3つを挙げています。
（1）や（3）は定量評価の分析を経て行われると期待されますが、（2）の意思決定の改善には、より「発見」の要素が大きな役割を果たしそうです。
ビッグデータ解析により、
+ 価値創造につながる新発見を誘発させるのか、
+ コストダウンのための知識や、製品・サービスの具体的な改良要求を抽出・整理する一助としたいのか
このような具体的な処方箋が描ける点で、現場主義、実践ノウハウ優先のダベンポート教授は、最初懐疑的だったと述べつつもビッグデータ活用の魅力にとらわれていったのだと思います。
