バックアップの基本知識
PostgreSQLでは主に2種類のバックアップ方法があります：
論理バックアップ：データベースを起動したままデータをファイルに書き出す方法
特定のテーブルやデータだけを抽出できる
別のバージョンのPostgreSQLにも移行しやすい
主なツール：pg_dump（単一DB用）、pg_dumpall（全DB用）
物理バックアップ：データファイルをそのままコピーする方法
大規模データベースの場合に高速
同じバージョンのPostgreSQLでのみ復元可能
初心者の方には論理バックアップがおすすめです。特に、pgAdmin
4というGUIツールを使うと、マウス操作だけでバックアップができます。
GUIを使ったバックアップ方法（pgAdmin 4）
準備
pgAdmin
4がインストールされていることを確認（PostgreSQLをインストールすると通常は一緒にインストールされます）
バックアップ手順
pgAdmin 4を起動する
Windowsのスタートメニューから「pgAdmin 4」を検索して起動します
サーバーに接続する
左側のブラウザパネルでサーバーをダブルクリックし、必要に応じてパスワードを入力
バックアップするデータベースを選択する
「データベース」フォルダを展開して、バックアップしたいデータベースを右クリック
メニューから「バックアップ...」を選択
バックアップ設定を行う
「ファイル名」：バックアップファイルの保存先と名前を指定
「形式」：初心者は「カスタム」または「タール」がおすすめ（圧縮されて容量が小さくなります）
「圧縮率」：通常は5～7程度
必要に応じて「ダンプオプション」タブで詳細設定も可能
バックアップを実行する
「バックアップ」ボタンをクリックして実行
完了すると「バックアップが完了しました」と表示されます
コマンドラインを使ったバックアップ方法
コマンドプロンプトを管理者として起動
PostgreSQLのbinディレクトリに移動
cd C:\Program
Files\PostgreSQL\[バージョン番号]\bin
pg_dumpコマンドを実行
pg_dump -U postgres -F c -b -v -f "C:\backup\mydb.backup" mydb
パラメータの説明：
-U postgres：ユーザー名（通常はpostgres）
-F c：カスタム形式でバックアップ
-b：バイナリ形式でデータを格納
-v：詳細なログを表示
-f "ファイルパス"：バックアップファイルの保存先
mydb：バックアップするデータベース名
パスワードを入力
実行するとパスワードを求められるので入力します (!QAZxsw2)
バックアップのリストア（復元）方法
pgAdmin 4を使ったリストア
リストア先のデータベースを作成または選択
既存のデータベースにリストアする場合は、そのデータベースを右クリック
新しいデータベースにリストアする場合は、まず「データベース」フォルダを右クリックして「データベースの作成...」を選択
リストアを実行
データベースを右クリックして「リストア...」を選択
「ファイル名」でバックアップファイルを指定
「形式」は自動的に検出されますが、確認のため正しい形式を選択
「リストア」ボタンをクリックして実行
コマンドラインを使ったリストア
カスタム形式・tar形式・ディレクトリ形式の場合（pg_restoreを使用）
pg_restore -U postgres -d mydb -v "C:\backup\mydb.backup"
テキスト形式の場合（psqlを使用）
psql -U postgres -d mydb -f "C:\backup\mydb.sql"
定期バックアップの設定方法
大切なデータベースは定期的に自動バックアップすることをおすすめします。Windowsのタスクスケジューラを使って設定できます。
バックアップ用のバッチファイルを作成
テキストエディタ（メモ帳など）を開く
以下の内容を入力して保存（例：db_backup.bat）
@echo off
set PGPASSWORD=yourpassword
set BACKUP_PATH=C:\backup
set
TIMESTAMP=%date:~0,4%%date:~5,2%%date:~8,2%_%time:~0,2%%time:~3,2%
set TIMESTAMP=%TIMESTAMP: =0%
"C:\Program
Files\PostgreSQL\[バージョン番号]\bin\pg_dump" -U postgres -F c -b -v -f
"%BACKUP_PATH%\mydb_%TIMESTAMP%.backup" mydb
echo バックアップが完了しました:
%BACKUP_PATH%\mydb_%TIMESTAMP%.backup
Windowsのタスクスケジューラを設定
「タスクスケジューラ」を開く（スタートメニューから検索）
右側の「基本タスクの作成...」をクリック
タスク名と説明を入力し「次へ」
トリガーを設定（例：毎日、毎週など）し「次へ」
アクションで「プログラムの開始」を選択し「次へ」
プログラムに作成したバッチファイルのパスを指定し「次へ」
「完了」をクリック
よくある問題と解決策
バックアップに時間がかかる
カスタム形式（-Fc）を使うと圧縮されるため時間短縮になります
大きなデータベースの場合はディレクトリ形式（-Fd）を使うと並列処理で高速化できます
「アクセス拒否」エラー
バックアップファイルの保存先に書き込み権限があるか確認
コマンドプロンプトを管理者として実行
「プログラムが見つかりません」エラー
PostgreSQLのbinディレクトリにパスが通っているか確認
フルパスで指定してみる
接続エラー
ホスト名、ポート番号、ユーザー名、パスワードが正しいか確認
PostgreSQLサービスが起動しているか確認
まとめ
PostgreSQLデータベースのバックアップは、データ保護の基本です。初心者の方には、まずはpgAdmin
4のGUIを使ったバックアップから始めることをおすすめします。慣れてきたらコマンドラインでのバックアップや、定期バックアップの設定にも挑戦してみてください。
重要なことは、バックアップを定期的に取ること、そしてリストア（復元）の方法も事前に確認しておくことです。実際に必要になった時に慌てないよう、一度テスト環境でリストアの練習をしておくと安心です。
