# Postgres 0埋め

SQL文で0埋めをする
方法1: LPAD関数を使用する
SELECT
LPAD(キャストする値::text, 埋める長さ, '0') FROM テーブル名;
（例）SELECT LPAD(id::text, 5, '0') FROM your_table;　　# id:数値
方法2:
TO_CHAR関数を使用する
SELECT　TO_CHAR(数値カラム,
'FM00000') FROMテーブル名;
（例）SELECT
TO_CHAR(id, 'FM00000') AS formatted_id FROM your_table WHERE id = 123;
