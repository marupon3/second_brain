# データベース削除

PostgreSQLでデータベースを削除するには、以下の手順に従ってください：
1. psqlにログイン: PostgreSQLのコマンドラインインターフェースであるpsqlにログインします。
cmd
psql -U your_username -h your_host -d your_database
(例）psql -U postgres -h localhost -d maruponDB
ユーザー postgres のパスワード:
* your_username（ユーザー名）:
PostgreSQLにアクセスするためのアカウントのユーザー名です。デフォルトでは「postgres」ですが、インストール時に他の名前に設定している場合もあります。ユーザー名はPostgreSQLの管理者が提供するか、インストール時に設定したものです。
* your_host（ホスト名）:
PostgreSQLサーバーが動作しているコンピュータのホスト名またはIPアドレスです。一般的には「localhost」（ローカルホスト）と呼ばれることが多いですが、リモートサーバーに接続する場合はそのIPアドレスやホスト名を使用します。
* your_database（データベース名）:
接続したい具体的なデータベースの名前です。データベース名は、PostgreSQLにログインして、 \l コマンドを実行することで確認できます。
1. データベース接続を終了:
削除したいデータベースに接続している場合は、まずそのデータベースから切断します。（他のデータベースに接続する）
sql
postgres-# \c
postgres
データベース"postgres"にユーザー"postgres"として接続しました。
1. データベースの削除: DROP
DATABASEコマンドを使ってデータベースを削除します。
sql
postgres-# \lDROP
DATABASE maruponDB;
1. データベース一覧表示:
sql
postgres-# \l
1. データベース一覧表示:
sql
postgres-# \q
