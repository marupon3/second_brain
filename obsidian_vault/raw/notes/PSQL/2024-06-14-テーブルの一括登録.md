# テーブルの一括登録

【cmd】   ユーザ名、テーブル名
psql
-U postgres -d tcmg
テーブル名(項目)、CSVファイルのPATH　(テーブルのSJIS, UTF-8形式とファイルの形式を合わせる）
tcmg=#
\copy
tkcode(depart,
stage, task, tkcode) FROM 'C:\\Users\\marupon\\Desktop\\new_data.csv'
DELIMITER ',' CSV HEADER;
1. \copyコマンド:
* PostgreSQLのクライアントであるpsqlで使用できるコマンドです。
* テーブルにCSVファイルのデータを一括でインポートする際に便利です。
2. tkcode(depart,
stage, task, tkcode):
* インポート先のテーブル名はtkcodeです。
* テーブルの各カラムはdepart, stage, task, tkcodeの4つです。
3. FROM
'C:\\Users\\marupon\\Desktop\\new_data.csv':
* インポートするCSVファイルのパスを指定しています。
* Windowsのファイルパスなので、バックスラッシュ\を2つ重ねて表現しています。
4. DELIMITER
',':
* CSVファイルのフィールド区切り文字が,(カンマ)であることを示しています。
5. CSV:
* ファイルフォーマットがCSVであることを示しています。
6. HEADER:
* CSVファイルの1行目がヘッダー行であることを示しています。
<<new_data.csv>>
PostgreSQLのバージョンが古い場合のコマンド　(sql)
1．CSVファイルの内容を確認します
\! cmd /c type "C:\Users\Administraton\Desktop\new_data.csv"
2．CSVファイルをコピーしてテーブルに挿入します (sql)
COPY tkcode
FROM 'C:\\Users\\Administraton\\Desktop\\new_data.csv'
WITH
CSV
HEADER;
