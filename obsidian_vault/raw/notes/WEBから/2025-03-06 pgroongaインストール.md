# _pgroongaインストール

for PostgreSQL
2025年3月6日
7:27
テキスト全文検索用拡張機能インストール
<https://pgroonga.github.io/install/windows.html>
download [pgroonga-4.0.1-postgresql-17-x64.zip](https://github.com/pgroonga/pgroonga/releases/download/4.0.1/pgroonga-4.0.1-postgresql-17-x64.zip)
Zipファイルを展開して、C:\Program
Files\PostgreSQL\17\　の各フォルダにコピーする。
(上書き保存するファイルはなかった）
PgAdmin4を使ってデータベース"pgroonga_test"を作成する。
CD
"C:\Program
Files\PostgreSQL\17\bin"
psql -U postgres -d pgroonga_test

pgroonga_test=#
CREATE EXTENSION pgroonga;
![](file1388.files/image002.png)
SQL文を実行する
＊＊＊
--
【SQL】ファイルカタログ用テーブルとインデックス作成スクリプト
CREATE TABLE IF
NOT EXISTS file_index (
id SERIAL PRIMARY KEY,
file_path TEXT UNIQUE NOT NULL,
content_hash BYTEA NOT NULL,
content_text TEXT,
last_indexed TIMESTAMP DEFAULT NOW(),
encoding VARCHAR(20)
);
--
PGroonga拡張を有効化（インストール済み前提）
CREATE EXTENSION
IF NOT EXISTS pgroonga;
--
日本語全文検索用インデックス (Mecab を利用)
CREATE INDEX IF
NOT EXISTS idx_content_search
ON file_index USING pgroonga (content_text)
WITH (tokenizer='TokenMecab',
normalizer='NormalizerAuto');
＊＊＊
このSQLスクリプトでは、ファイルインデックス用のテーブルを作成し、PGroonga拡張を有効化した後、MeCabトークナイザとNormalizerAutoノーマライザを使用した日本語全文検索用のインデックスを作成しています。
