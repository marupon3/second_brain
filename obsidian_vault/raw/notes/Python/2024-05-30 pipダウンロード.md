# pipダウンロード

python
-m pip download -d C:\module pip
C:\pip_filesにモジュールのファイル（.whlファイル）がダウンロードされる
pip download
fastapi
pip download
uvicorn
コマンドプロンプトを実行したディレクトリに（.whlファイル）がファイルが保存される
モジュールのインストール（インターネットが利用できないサーバ等へのインストール）
インストールを実行する前に仮想環境に入っておく
プロジェクト名>venv\scripts\activate
【pipインストール】
(venv) cd C:\module (moduleはモジュールが入っているフォルダ名：任意の名前で良い）
python -m pip
install --no-index --find-links=. pip
【一般のモジュールインストール】
(venv) cd C:\module
pip install
--no-index --find-links=. <モジュール名>
