# _暗号化システムのセットアップ

ステップ1: cryptographyライブラリのインストール
powershell
pip install cryptography --break-system-packages
実行してください ↑
ステップ2: インストール確認
powershell
python -c "from
cryptography.hazmat.primitives.ciphers.aead import AESGCM; print('OK -
cryptography installed')"
ステップ3: 暗号化キーの生成
powershell
python generate_key.py
選択肢:
* オプション1:
Windows環境変数に保存（推奨）
* オプション2: ファイルに保存
* オプション3: 画面表示のみ
⚠️ 超重要:
生成されたキーを必ずメモ帳などにコピーして保存してください！
ステップ4: .envファイルの暗号化
powershell
python encrypt_env.py
* 元の.envファイルは削除されます
* .env.encryptedファイルが作成されます
ステップ5: 動作確認
powershell
python waitress_server.py
