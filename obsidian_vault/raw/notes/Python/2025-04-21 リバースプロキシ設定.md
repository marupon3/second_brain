# リバースプロキシ設定

IIS＋ARR
を用いた場合
+ IIS
の機能追加
- コントロールパネル → プログラムと機能 →
「Windows の機能の有効化または無効化」→ Internet Information Services にチェック
<https://www.floatgarden.net/server/windows10_iis_server.html>
- ![](file0362.files/image001.png)
+ 拡張モジュールの導入
- [URL Rewrite](https://www.iis.net/downloads/microsoft/url-rewrite) Module と [Application Request
Routing](https://www.iis.net/downloads/microsoft/application-request-routing)
を Web Platform Installer などでインストール
+ リバースプロキシ設定
- IIS マネージャ起動 → サーバー名選択 →
「URL 書き換え」→「操作」→「ルールの追加」→「リバース プロキシ」 → “127.0.0.1:8000” を入力
- ![](file0362.files/image002.png)
- 必要に応じてバインド（ポート80）設定、SSL証明書バインド
+ ファイアウォール許可
- 同様にポート80を開放
＝＝＝＝＝＝
サーバー レベルで ARR（リバースプロキシ）を設定したい場合
左ペイン最上位の「<コンピュータ名>」 を選択
画面中央に「機能ビュー」が表示されるので、その中の 「URL 書き換え」 を開き
右ペイン「操作」→ 「ルールの追加…」→ 「リバース プロキシの規則」 を選択
プロキシ先に 127.0.0.1:8000（Waitress
の待ち受け）を入力して適用
こうすると、このサーバー上の全サイトで同じルールが働きます。
特定サイト（例：Default Web
Site）だけに適用したい場合
左ペインで Sites → Default Web Site（または任意のサイト名）
を選択
同じく「URL 書き換え」→「規則の追加」→「リバース プロキシ」と進み
プロキシ先を設定
![](file0362.files/image003.png)
![](file0362.files/image004.png)
![](file0362.files/image005.png)
「URLの書き換え」欄が「[http://127.0.0.1:8000/{R:1}](http://127.0.0.1:8000/%7bR:1%7d)」になっていればOK
