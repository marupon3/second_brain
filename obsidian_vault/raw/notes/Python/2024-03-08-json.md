はい、jsonファイルからデータを読み込んで、複数のPythonファイルから利用する方法をお見せします。
まず、config.jsonというjsonファイルを作成し、次のようなデータを入れます。
json　config.jsonファイル
{
"api_key":
"YOUR_API_KEY",
"database": {
"host":
"localhost",
"user":
"YOUR_USERNAME",
"password":
"YOUR_PASSWORD"
}
}
次に、config.pyというファイルを作成し、jsonファイルを読み込むコードを書きます。
python　config.pyファイル

<!-- 変換時の注記: OneNote由来の改行を括弧深さ/構文解析で自動復元しました。インデントはOneNote側で失われている場合があり保証されません。実行前に必ず目視確認してください（要確認）。 -->

```python
import json
def load_config():
    with open("config.json", "r") as f:
        config = json.load(f)
    return config
#
config変数にデータを読み込む
config = load_config()
このconfig変数には、jsonファイルのデータが辞書型で格納されています。 次に、別のPythonファイルからconfig変数を利用する例を示します。 python　main.pyファイル:
from config import config
#
config変数からデータを取得
api_key = config["api_key"]
db_host = config["database"]["host"]
print(f"API Key: {api_key}")
print(f"Database Host: {db_host}")
main.pyを実行すると、次のように出力されます。 API Key: YOUR_API_KEY Database Host: localhost このように、config.pyファイルで読み込んだ設定データを、複数のPythonファイルから簡単に利用できます。jsonファイルの内容を変更すれば、アプリケーション全体の設定を一か所で管理できる便利な方法です。
```
