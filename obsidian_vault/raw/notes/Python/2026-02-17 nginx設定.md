# _nginx設定

<https://nginx.org/en/download.html>
1. Nginx for
Windows をダウンロード
2. nginx/ ディレクトリに配置
3. generate_cert.ps1 で証明書生成
4. Flask起動 → Nginx起動 → <https://localhost/KONETA/auth/login> でアクセス確認
![](file6074.files/image001.png)
証明書作成
cd C:\Users\marupon\PycharmProjects\koneta\nginx
powershell
-ExecutionPolicy Bypass -File .\generate_cert.ps1

Nginx起動
エクスプローラーで、以下のファイルをダブルクリック（管理者権限で実行）
C:\Users\marupon\PycharmProjects\koneta\nginx\start_nginx.bat

ポート 80→8080、443→8443 に変更

ポート番号を .flaskenv の NGINX_HTTPS_PORT から取得
