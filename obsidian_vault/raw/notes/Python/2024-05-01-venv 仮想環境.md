# venv 仮想環境

プロジェクト毎に仮想環境を作る
>cd [プロジェクト名のパス]
>python -m venv venv
>venv\scripts\activate
pip最新版にアップグレードする
>python -m pip install --upgrade pip
>pip install flask (例　FLASKをインストール）
環境変数の設定
[20240304 使用中のポートを解放する](onenote:#20240304%20使用中のポートを解放する&section-id={CE6A8A59-4609-405D-BDF1-758F8E34FC50}&page-id={F961AB65-B467-4E3F-922E-3C9801D2F796}&end&base-path=https://d.docs.live.net/b2dce0c6e69fc906/OneNote%20ノートブック-DESKTOP-3BGGGLU/仕事用/Python.one)
>set FLASK_APP=main.py
>set FLASK_ENV=development
アプリケーションの実行
>flask run
プロジェクトの仮想環境から離脱する
>deactivate
プロジェクトの仮想環境ファイルを削除する
>rmdir /s /q venv
|  |  |
| --- | --- |
| オプション | 機能 |
| /s | 指定されたディレクトリに加えて、そのディレクトリ内のすべてのディレクトリとファイルを削除します。ディレクトリ ツリーを削除するときに使用します。 |
| /q | /S を指定してディレクトリ ツリーを削除するときに、確認のメッセージを表示しません。(QUIET モード) |
