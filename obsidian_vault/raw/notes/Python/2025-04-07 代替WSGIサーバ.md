# _代替WSGIサーバ

次の警告が出たときの対応（開発環境なら無視してよい）
WARNING: This is
a development server. Do not use it in a production deployment. Use a
production WSGI server instead.
Windows環境での本番サーバーとしては、Waitressなどの代替WSGIサーバを使用
pip install
waitress
Pythonプログラムを実行するコマンド
waitress-serve --port=8000 main:app
waitress-serve --host 127.0.0.1 --port 8000 main:app
【Flask】 WSGI
サーバーに Waitress を使用する
<https://lazy-developer.jp/flask-wsgi-waitress>
