# バージョンを指定して仮想環境を作成

前提と想定
* WindowsにPythonを複数バージョン（例：3.7、3.9）がインストールされている
* 各バージョンは公式インストーラで導入し、Python
Launcher（pyコマンド）が使える状態
* これから作る仮想環境には、特定バージョンのインタプリタを明示的に指定する
全体のステップ
1. インストール済みのPythonバージョンをリストアップ
2. Python Launcher (py)
またはインタプリタのフルパスで仮想環境を生成
3. 仮想環境を有効化し、正しいバージョンになっているか確認
1.
インストール済みバージョンの確認
#
Windows標準のPython Launcherで一覧を表示
py -0p
-0：インストール済みバージョン一覧
-p：インタプリタのパスも表示
2. venvモジュールで仮想環境を作成
1. Python
Launcherを使う
#
例：Python 3.9 で .venv39 ディレクトリを作成
py -3.9 -m venv .venv39
1. フルパス指定
# 例：C:\Python39\python.exe
を使って仮想環境を作成
C:\Python39\python.exe -m venv venv
3. 仮想環境の有効化と確認
#
仮想環境を有効化
venv39\Scripts\activate
#
有効化後、Pythonのバージョンを確認
python
--version
#
→ Python 3.9.x と表示されれば成功
