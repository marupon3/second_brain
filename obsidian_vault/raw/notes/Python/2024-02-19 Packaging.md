Pycharm 2021.3 の仮想環境にPython
Packaging Toolsをインストールする方法
設定のインタープリターからPackaging Toolsがインストールできなかった場合の対応
Pycharm 2021.3 が　Python
3.12に対応していないためと思う
>（仮想環境のpythonのフルパス）　-m pip install packaging tools
仮想環境で、ターミナルを開き以下のコマンドを入力する。
python -m pip install --upgrade pip setuptools wheel
python -m pip install packaging tools
