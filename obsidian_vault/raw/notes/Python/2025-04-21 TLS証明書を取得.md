# _SSL/TLS証明書を取得

1. 商用CAから証明書を購入する方法
1‑1. CSR（証明書署名要求）の作成
1. IIS マネージャーを管理者権限で起動
1. 左ペインでサーバー名を選択 → 中央「機能ビュー」から 「サーバー証明書」 をダブルクリック
2. 右ペインの 「証明書要求の作成…」 をクリック
3. ダイアログで以下を入力
* 共通名
(CN)：アクセスに使うドメイン名（例：www.example.com）
* 組織名/部署：会社名や部門名
* 市区町村、都道府県、国：お住まいまたは法人登記の住所
1. ファイル名 を指定し（例：C:\certs\example_com.csr）、保存
1. 生成された .csr ファイルを次のステップでCAに提出
1‑2. CAへCSRを提出し、証明書を発行
1. 購入先のCA（例：Digicert、GlobalSign、Sectigoなど）のWebサイトにログイン
2. 「SSL証明書の新規発行」→
CSRファイルをアップロード
3. ドメイン所有確認（メール認証やDNSレコード認証など）を完了
4. 数分〜数時間で、CAから 証明書ファイル（.cer
など）
がメールまたはダウンロードリンクで届く
1‑3. IISへ証明書を取り込み
1. IIS マネージャー → サーバー名 → 「サーバー証明書」 → 「証明書要求の完了…」
2. CAから届いた .cer
ファイルを指定して取り込み
1‑4. PFX形式でエクスポート
1. IIS マネージャー → サーバー名 → 「サーバー証明書」 → 対象証明書を選択
2. 右ペインの 「エクスポート…」 をクリック
1. ファイル名（例：C:\certs\example_com.pfx）と パスワード を設定して保存
1. これで .pfx ファイルが手に入ります
2. Let’s Encrypt（無料）を使う方法
Let’s Encrypt
は自動更新が可能な無料のSSL証明書です。Windows環境では win-acme
というツールを使うのが簡単です。
2‑1. win‑acme の入手
1. 公式サイト（https://www.win-acme.com/）から最新版の
ZIP をダウンロード
2. サーバー上で任意のフォルダ（例：C:\tools\win-acme）に解凍
2‑2. 証明書の取得＆IIS連携
1. PowerShell
やコマンドプロンプトを管理者権限で起動
2. win‑acme フォルダに移動して
wacs.exe を実行
3. メニューから 「N:
Create new certificate (simple for IIS)」 を選択
4. IIS
に登録済みのサイト一覧が表示されるので、あなたの Flask サイト名（例：FlaskApp）を選択
5. 自動的にドメイン認証（HTTP-01）→
証明書取得 → IIS へのバインド設定 → PFX 生成まで実行
6. 処理が完了すると、証明書ストアにも PFX
が登録されます
2‑3. PFX の場所とパスワード
* win‑acme は既定で Windows
証明書ストアに格納しますが、必要であれば 「Export Certificates」 メニューから PFX を書き出せます。
* 書き出し時にパスワードを設定し、後のバインドで利用します。
