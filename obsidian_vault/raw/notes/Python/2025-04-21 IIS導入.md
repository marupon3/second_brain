# _IIS導入

サーバーマネージャーで IIS を導入する （Windows Server)
1. サーバーマネージャー を開き、右上の 「管理」→「役割と機能の追加」 をクリック
1. 「インストールの種類」は 「役割ベースまたは機能ベースのインストール」
2. 対象サーバーを選択し、「サーバーの役割」 で 「Web サーバー (IIS)」 をチェック
3. ポップアップで依存機能を 「機能の追加」
4. 続く「機能」の画面では特に追加不要（必要に応じて
.NET Extensibility 4.x／CGI など）
5. 「Web
サーバーの役割サービス」では以下を確認・追加
* 共通 HTTP
機能：静的コンテンツ、HTTP
リダイレクト
* セキュリティ：windows認証
* アプリケーション開発：CGI（必要時）、ASP.NET は不要（Flask
側で処理）
* 管理ツール：IIS
管理コンソール
1. 「インストール」 を実行し、完了を待つ
Windows10, 11で IIS を導入する
「コントロールパネル」を開き、「プログラムと機能」を選択する。
左側のメニューから「Windowsの機能の有効化または無効化」をクリックする。
「インターネットインフォメーションサービス」にチェックを入れて「OK」を押下
![](file3621.files/image001.png)
IIS マネージャーでリバースプロキシを設定
1. IIS マネージャー を起動し、左ペインでサーバー名を選択
1. 中央に 「Application
Request Routing キャッシュ」 が表示されるのでダブルクリック
2. 右ペインの 「サーバー
プロキシの設定」 → 「プロキシを有効にする」 にチェック → 適用
3. 左ペインで公開用サイト（例：既定の Web
サイト）を選択し、「URL 書き換え」 をダブルクリック
4. 右ペインの 「操作」→「規則の追加」→「リバース
プロキシ」
* 受信規制：localhost:8000（Waitress
の待ち受けポート）
* 必要に応じてパス／ポートを調整し、「承諾」
5. 自動で生成される Inbound ルールを確認し、パターン
(.*) → 書き換え先 [http://localhost:8000/{R:1}](http://localhost:8000/%7bR:1%7d) となっていることを確認

解決策：IIS に Flask 用サイトを追加する
1. IIS マネージャーを開く
1. 左ペインでサーバー名の下にある
「Sites」 を右クリック
1. 「Web サイトの追加 (A)…」 を選択
1. 以下を入力して OK
* サイト名：任意（例：FlaskApp）
* 物理パス：実ファイルは不要なら空フォルダ（例：C:\inetpub\FlaskApp）
* バインド
+ 型：http（あるいは後から https
を追加）
+ IP アドレス：すべて未割り当て
+ ポート：80（Default Web Site
と競合する場合は別ポートかホスト名で分ける）
+ ホスト名：必要に応じて（例：flask.example.com）
