# _Windowsファイアウォール設定

waitressを使ってサーバにアクセスする設定
<PowerShell>
New-NetFirewallRule `
-DisplayName
"Allow Waitress 8000" `
-Direction
Inbound `
-Action
Allow `
-Protocol
TCP `
-LocalPort
8000
ポートを開放する設定
ファイアウォールで開放したルールをそのまま削除してポートを閉じるには、Remove-NetFirewallRule コマンドを使います。管理者権限の
PowerShell で以下を実行してください。
# ルール名 ("Allow Waitress 8000") を指定して削除
Remove-NetFirewallRule -DisplayName "Allow
Waitress 8000"
もし、名前が重複していたり確実に該当ルールを取得してから削除したい場合は、パイプでつないでもOKです。
Get-NetFirewallRule -DisplayName "Allow
Waitress 8000" | Remove-NetFirewallRule
また「無効化」しておいて後で有効化したい場合は、以下のように
-Enabled パラメータで切り替えも可能です。
# ルールを無効化（ポートは閉じたままルール定義だけ残す）
Set-NetFirewallRule -DisplayName "Allow
Waitress 8000" -Enabled False
# 再度開放したいときは
Set-NetFirewallRule -DisplayName "Allow
Waitress 8000" -Enabled True
＊＊＊＊
1. ルール作成（ポート開放）
#
管理者 PowerShell で実行
New-NetFirewallRule `
-Name
"AllowWaitress8000" `
-DisplayName
"Allow Waitress 8000" `
-Direction
Inbound `
-Action
Allow `
-Protocol
TCP `
-LocalPort
8000
2. ルールの状態確認
#
作成したルールの存在と状態をチェック
Get-NetFirewallRule -Name
"AllowWaitress8000" |
Format-Table
Name, DisplayName, Enabled, Direction, @{N='Port';E={$_.LocalPort}}
3. ルールを無効化（ポートを閉じる）
#
一時的に閉じたいだけなら Disable
Set-NetFirewallRule -Name
"AllowWaitress8000" -Enabled False
4. ルールを再度有効化（ポート開放）
#
再び開放したいとき
Set-NetFirewallRule -Name
"AllowWaitress8000" -Enabled True
5. ルール削除（定義ごと消す）
#
完全に削除したいとき
Remove-NetFirewallRule -Name
"AllowWaitress8000"
