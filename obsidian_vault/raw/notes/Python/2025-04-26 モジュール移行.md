# _モジュール移行

案1.
venv＋requirements.txt
1. 仮想環境をアクティベート
cd C:\path\to\project
\venv\Scripts\activate
1. 現在インストール済みパッケージを一括で出力
pip freeze > requirements.txt
#
コメントは行頭に # を付ける
Flask==2.2.3          # 厳密にバージョン2.2.3を指定
requests>=2.28.0      # バージョン2.28.0以上
numpy<1.25.0          # 1.25.0未満
pandas                # バージョン未指定（最新がインストールされる）
==:
完全一致
>=／<=:
範囲指定
複数の条件も可能：Django>=3.2,<4.0
コメント行（#
～）で補足情報を書けます
