3. ログ記録用のミドルウェア実装

Windows Server環境での注意点
Windows
Server環境では、以下の点に注意する必要があります：
1. ファイルパスの扱い：
* Windowsではバックスラッシュ(\)がパス区切り文字ですが、コードではos.path.joinを使用して問題を回避しています。
2. ファイルロック：
* Windows環境ではSQLiteファイルのロックが厳しいため、複数のプロセスからの同時アクセスに注意が必要です。
* これを解決するために、スレッドローカルストレージを使用してデータベース接続を管理しています。
3. 権限：
* instanceディレクトリが作成できる権限があることを確認してください。
* Windowsサービスとして実行する場合は、サービスアカウントに適切な権限を付与してください。
使い方
1. アプリケーションを起動すると、自動的にデータベースが初期化され、アクセスログの記録が開始されます。
コマンドラインからログの操作が可能です：
flask init-db  # データベースを再初期化
flask export-logs --days 30  #
過去30日のログをCSVに出力
flask init-dbでうまくいかないときは次のコマンドを使う
＊ python -m flask init-db
1. アクセスログの分析には、SQLiteクライアント（DB
Browser for SQLiteなど）を使用できます。

Browser for SQLite: [公式サイト](https://sqlitebrowser.org/)　→　インストール
* SQLiteStudio: [公式サイト](https://sqlitestudio.pl/)
