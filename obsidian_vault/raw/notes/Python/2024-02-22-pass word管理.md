# pass word管理

pyファイルと同じ階層に、「.emv」というテキストファイルを作り以下の設定をする
DB_USER=user_name
DB_PASSWORD=pass_word
以下のように使う
from dotenv impor tload_dotenv

```python
import os
#
環境変数をロードするload_dotenv()
#
環境変数からデータベース接続情報を取得するdb_user = os.getenv("DB_USER")
db_password = os.getenv("DB_PASSWORD")
#
値を表示するprint("Database User:", db_user)
print("Database Password:", db_password)
環境変数は、オペレーティングシステムに設定される変数で、実行中のプロセスに対して特定の情報（この場合、IDやパスワード）を提供するために使用されます。Pythonコードでは、osモジュールを使用してこれらの環境変数にアクセスできます。 keyringモジュールの利用 keyringは、パスワードなどの機密情報を安全に保存し、プログラムからアクセスするためのライブラリです。Windowsでは、Credential Vaultにアクセスすることで情報を安全に管理します。 まずはkeyringをインストールします。 cmd pip install keyring 次に、keyringを使用して認証情報を設定・取得する基本的な使い方です。 Python import keyring # 認証情報を保存 keyring.set_password("system", "username", "password") # 認証情報を取得 password = keyring.get_password("WindowsID", "username") この方法では、機密情報がOSのセキュリティシステムによって保護されます。 参考URL [パスワードをハードコーディングしないためのTips](https://scrapbox.io/PythonOsaka/%E3%83%91%E3%82%B9%E3%83%AF%E3%83%BC%E3%83%89%E3%82%92%E3%83%8F%E3%83%BC%E3%83%89%E3%82%B3%E3%83%BC%E3%83%87%E3%82%A3%E3%83%B3%E3%82%B0%E3%81%97%E3%81%AA%E3%81%84%E3%81%9F%E3%82%81%E3%81%AETips) [python-dotenvを使って環境変数を設定する](https://qiita.com/harukikaneko/items/b004048f8d1eca44cba9)
```
