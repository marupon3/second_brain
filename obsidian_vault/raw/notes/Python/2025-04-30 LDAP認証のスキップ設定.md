# _LDAP認証のスキップ設定

LDAPをスキップする/しないの設定をコードに書き込んでおく
LDAPをスキップ
(PowerShell) $env:SKIP_LDAP = 'true'
(DOS) set SKIP_LDAP=true
python
waitress_server.py
LDAPをスキップしない
(PowerShell) $env:SKIP_LDAP = 'false'
(DOS) set SKIP_LDAP=false
python
waitress_server.py
Flaskアプリケーション統一修正案
1. 共通点と相違点の分析
現状の2つのWebアプリケーション（crudとpulldownlist）を分析した結果、以下の点で書き方が異なっています：
|  |  |  |
| --- | --- | --- |
| 機能 | crud | pulldownlist |
| アプリ初期化 | 環境変数を直接取得 | dotenvを使用 |
| DB初期化 | 専用関数 | 単一関数 |
| 認証処理 | ハードコーディング | 共通関数 |
| エラーハンドリング | try-except | 最小限 |
| ディレクトリ構造 | 一部異なる | 一部異なる |
| ルーティング | Blueprint | Blueprint |
| ログ処理 | 共通 | 共通 |
2. 修正方針
以下の点を統一することで、メンテナンス性を向上させます：
1. 環境変数の取得方法を統一する
2. データベース初期化と接続処理を統一する
3. 認証処理を統一する
4. エラーハンドリングの方法を統一する
5. ディレクトリ構造の表記を統一する
