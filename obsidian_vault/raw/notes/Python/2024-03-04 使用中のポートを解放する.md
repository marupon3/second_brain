# 使用中のポートを解放する

使用中のポートを特定して解放する
もし特定のポートを使用したい場合は、そのポートを使用しているプロセスを特定して終了させる必要があります。どのプロセスがポートを使用しているかを特定する方法は、使用しているオペレーティングシステムによって異なります。
Windowsの場合:
コマンドプロンプトまたはPowerShellを開き、以下のコマンドを実行して、ポート5000を使用しているプロセスのPID（プロセスID）を見つけます。
cmd
netstat
-ano | findstr :5000
PIDを特定したら、以下のコマンドを使用してそのプロセスを強制終了します（<PID>は実際のプロセスIDに置き換えてください）。
cmd
taskkill /PID <PID> /F
再接続
目的のディレクトリで、環境変数を変更する
方法1：set FLASK_APP=main:app
方法2：set FLASK_APP=[main.pyの一つ上のフォルダ名]
方法3：バッチファイルを作成し、実行する
@echo
off
set
FLASK_APP=main:app
flask
run
ENVの設定：set
FLASK_ENV=development
対象のpyファイルを起動させる
方法1：>python main.py　　（main.pyからflaskを使う場合）
方法2：>flask --app [main.pyの一つ上のフォルダ名] run
方法3：プロジェクト直下で
>flask run
