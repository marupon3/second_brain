# C++ Build Toolsのインストール

C++ Build
Tools　のインストール
<https://visualstudio.microsoft.com/ja/visual-cpp-build-tools/Microsoft>
ダウンロードしたインストーラーを実行し、「C++
build tools」のオプションを選択してインストールします。インストール中に「Windows 10 SDK」と「最新のWindows 10
SDK」のような追加コンポーネントが提示される場合もあります。これらは、将来的に他のパッケージをビルドする際に役立つ可能性があるため、選択することをお勧めします。
