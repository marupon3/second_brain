# Claude用スキル構築の完全ガイド（非公式日本語翻訳版）要約

## 概要
スキルとは、特定のタスクやワークフローをClaudeに教えるためのパッケージ化された指示セット。  
繰り返しの説明を不要にし、一貫した高品質な実行を可能にする強力なカスタマイズ手段。  
MCP連携と組み合わせると特に効果的。

## スキルの基本構造
- 必須：SKILL.md（YAMLフロントマター + Markdown指示）
- 任意：scripts/（実行コード）、references/（ドキュメント）、assets/（テンプレート等）

## コアデザイン原則
1. プログレッシブ・ディスクロージャー（3層構造でトークン節約）
2. コンポーザビリティ（他スキルと併用可能）
3. ポータビリティ（Claude.ai / Claude Code / APIで共通）

## 主なユースケースカテゴリ
1. ドキュメント・資産作成（スタイルガイドやテンプレート活用）
2. ワークフロー自動化（段階的プロセス・検証付き）
3. MCP強化（ツール呼び出しを信頼性の高いワークフローに変換）

## 計画・設計のポイント
- 2〜3の具体的ユースケースから始める
- 成功基準を定量・定性で定義
- YAMLフロントマターが最重要（name + description必須。トリガー条件を明確に）

## 効果的な記述法
- description：「何をするか」＋「いつ使うか」＋具体的フレーズを含める
- 指示は具体的・実行可能に。エラーハンドリングと例を追加
- 詳細はreferences/に分離

## テストと反復
- トリガーテスト／機能テスト／パフォーマンス比較を実施
- スキルクリエイターを活用（15〜30分で初版作成可能）
- アンダー／オーバートリガーや実行不具合に応じて改善

## 配布方法
- 個人：フォルダをZIP化してClaude.aiにアップロード or Claude Codeに配置
- 組織：ワークスペース全体に展開可能
- 推奨：GitHub公開 + MCPドキュメントへのリンク

## 主要パターン
1. 逐次ワークフローオーケストレーション
2. マルチMCP調整
3. 反復的改善
4. コンテキストに応じたツール選択
5. ドメイン特化型インテリジェンス

## トラブルシューティング要点
- アップロード失敗 → SKILL.mdの正確な命名とYAML形式を確認
- トリガーされない → descriptionの具体性を強化
- 過剰トリガー → ネガティブトリガーやスコープ明確化
- 指示無視 → 簡潔化・重要事項の強調・スクリプトによる検証

## 結論
このガイドに従えば、1回のセッションで実用的なスキルを構築可能。  
必ずオリジナル版を確認の上で活用を推奨。
