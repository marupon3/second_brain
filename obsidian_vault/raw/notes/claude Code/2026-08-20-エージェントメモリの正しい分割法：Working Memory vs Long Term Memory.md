**AIエージェントの「ワーキングメモリ」と「長期メモリ」を分けるべき、という投稿の要約です。**

### ポイント
一時的なメモ（スクラッチノート）と永続的な事実を混ぜると、将来の実行を汚染してしまう。  
そのため、エージェントのメモリを**ワーキングメモリ**と**長期メモリ**に明確に分離する必要がある、と述べています。

### メモリ分離のチートシート
1. ワーキングメモリは1つのタスクに限定する  
2. 検証済みの事実だけを長期メモリに昇格させる  
3. ツールの生出力をそのまま長期メモリに入れない  
4. 長期メモリからの取得は関連度スコアを使う  
5. タスク終了時にワーキングメモリをクリアする  
6. 昇格内容を定期的にレビューする  

**核心の原則**  
「一時的なノイズを永久的な知識にしてはいけない」

**プロのコツ**  
昇格は「偶然」ではなく「明示的な書き込み」にする。

投稿には「Working Memory vs Long Term Memory」のインフォグラフィックも添付されており、  
- ワーキングメモリ：現在のタスク用の一時的・容量制限付きの作業空間  
- 長期メモリ：事実・知識・スキルを蓄える永続的な知識ベース  

という対比と、Promote（昇格）／Retrieve（取得）／Expire（削除）の流れが図解されています。  

「あなたはどうやってこの2つを分けていますか？」と読者に質問して締めくくっています。
