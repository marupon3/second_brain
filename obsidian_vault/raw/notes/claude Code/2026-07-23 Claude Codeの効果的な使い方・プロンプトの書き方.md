## 要約

動画は、AnthropicのClaude Code（ターミナルで動くエージェント型コーディングツール）を開発したエンジニア（Boris Cherny氏）による、効果的な使い方・プロンプトの書き方に関するセッションです。スライドを使った講演形式で、インストールから高度な活用までを解説しています。

### 主な内容
1. **インストールと初期セットアップ**  
   `npm install -g @anthropic-ai/claude-code` で簡単に導入。その後、セットアップを最適化するための各種スラッシュコマンドを紹介（例: `/allowed-tools`、`/install-github-app`、`/config`、`/theme`、通知設定、Macの音声入力など）。

2. **コードベースに関する質問への活用**  
   プロジェクトのコードについて具体的な質問を投げる例を多数紹介。  
   - 特定のコントローラーがどこで使われているか  
   - 例外処理の引数が多い理由（git履歴を調べる）  
   - バグ修正の経緯  
   - 特定APIがどのバージョンでリリースされたか  
   - 先週何を出荷したか  
   など、「探して・調べて・答えて」という使い方が強力であることを示しています。

3. **チームのツールを連携させる（MCP）**  
   独自のMCPサーバーや社内ツールをClaudeに認識させ、エラーログ確認や特定の操作を自然言語で指示できるようにする方法。

4. **コンテキストの与え方（核心部分）**  
   **CLAUDE.mdファイル**を階層的に使うことが強調されています。  
   - エンタープライズ全体共通  
   - ユーザー個人（`~/.claude/CLAUDE.md`）  
   - プロジェクトルート（共有用）  
   - ローカル専用（チェックインしない）  
   これにより、毎回同じ説明をせずに「プロジェクトの慣習・コマンド・スタイル・アーキテクチャ」を自動でClaudeに教えられます。  
   「コンテキストを多く与えるほど賢くなる」「時間をかけてコンテキストをチューニングせよ」というTipsも提示。

5. **その他のポイント**  
   - 並列セッションの活用  
   - メモリのショートカット  
   - Claude Code SDKの紹介  
   - 効果的なプロンプトパターン（結果を指示し、手順は任せるなど）

動画の最後はQ&Aと「このセッションを楽しんでくれたら感想を」という締めです。

### ツイートのポイントとの対応
投稿者が強調している通り、**CLAUDE.mdによる永続的なメモリ/コンテキスト管理**、**効率的なプロンプトの書き方**、**並列セッション**、**実践的なワークフロー**が中心で、表面的なプロンプトテンプレート集ではなく「実際にどう使えば生産性が劇的に上がるか」を教えています。初心者から上級者まで役立つ内容で、有料講座の内容を超える密度がある、というのが投稿の主張です。
