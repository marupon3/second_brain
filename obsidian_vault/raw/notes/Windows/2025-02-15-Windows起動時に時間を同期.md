# Windows起動時に時間を同期

Windows
11の起動時にコマンドを自動実行する方法をご説明します。タスクスケジューラを使用して設定します。
1. タスクスケジューラを開きます：
* Windowsキー +
Rを押してtaskschd.msc」「と入力
* または、スタートメニューで「タスクスケジューラ」を検索
2. 左側のツリーで「タスクスケジューラライブラリ」を選択
3. 右側のペインで「基本タスクの作成」をクリック
4. 以下の手順で設定を行います：
* 名前：「NTP Time Sync at
Startup」（任意の名前）
* トリガー：「コンピューターの起動時」を選択
* 操作：「プログラムの開始」を選択
* プログラム/スクリプト：C:\Windows\System32\w32tm.exe
* 引数の追加：/resync /force
5. タスクの設定を完了後、以下の追加設定を行います：
* 作成したタスクをダブルクリック
* 「プロパティ」で「セキュリティオプション」タブを開く
* 「最上位の特権で実行する」にチェックを入れる
* 「構成」で「Windows 11」を選択
これで、Windows
11起動時に時刻同期が自動的に実行されるようになります。
設定後、手動でタスクを実行してテストすることもできます：
* タスクを右クリックして「実行」を選択
注意：このタスクが正しく動作するためには、Windows
Timeサービスが実行されている必要があります。
