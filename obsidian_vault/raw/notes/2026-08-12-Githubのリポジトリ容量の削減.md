# GitHub の diskUsage を最大限減らすための完全ロードマップ

## ① LFS 導入（今後の肥大化防止）
## ② BFG / filter-repo で巨大ファイルを履歴から削除（容量削減）
## ③ 履歴初期化（最終的に容量をゼロに近づける）

### STEP 1：通常 clone で LFS を導入（予防策）
cd C:\Users\marupon\PycharmProjects\second_brain
git lfs install
git lfs track "*.png"
git lfs track "*.jpg"
git lfs track "*.jpeg"
git lfs track "*.pdf"
git add .gitattributes
git commit -m "Enable LFS for large files"
git push

### STEP 2：巨大ファイルを履歴から削除（容量削減の本丸）
例：画像を履歴から完全削除
bfg --delete-files *.png
bfg --delete-files *.jpg
bfg --delete-files *.jpeg
bfg --delete-files *.pdf

例：特定フォルダを削除
pip install git-filter-repo
cd C:\Users\marupon\PycharmProjects\second_brain
git filter-repo --path assets --invert-paths

BFG 後
git reflog expire --expire=now --all
git gc --prune=now --aggressive
git push --force

### **STEP 3：履歴ごと初期化（最終的に容量をゼロにする）**
巨大ファイルが大量にある場合、 最終的に **履歴初期化が最も確実に容量を減らします。**
git checkout --orphan latest_branch
git add -A
git commit -m "Initial clean commit"
git branch -D main
git branch -m main
git push -f origin main
