# Youtubuの音声を保存

月曜日
19:34
✅
yt-dlp
を使ってmp4で保存する方法
1. インストール（まだなら）
brew install yt-dlp
ffmpeg
2. YouTube動画をmp4形式で保存
yt-dlp -f
"bestvideo[ext=mp4]+bestaudio[ext=m4a]/mp4" -o
"~/Movies/%(title)s.%(ext)s" <https://www.youtube.com/watch?v=XXXXXXXXXXX>
|  |  |
| --- | --- |
| オプション | 意味 |
| -f "bestvideo[ext=mp4]+bestaudio[ext=m4a]/mp4" | mp4形式の映像＋音声を選択 |
| -o "~/Movies/%(title)s.%(ext)s" | 保存先とファイル名テンプレート |
| <https://www.youtube.com/watch?v=XXXXXXXXXXX> | 対象のYouTube動画URL |
3. 音質や画質を固定したい場合
例：720pで保存したい場合
yt-dlp -f
"bestvideo[height<=720][ext=mp4]+bestaudio[ext=m4a]/mp4" <https://www.youtube.com/watch?v=XXXXXXXXXXX>
4. 音声だけをmp4（M4A形式）で保存したい場合
yt-dlp -f bestaudio
--audio-format m4a -o "~/Music/%(title)s.%(ext)s" <https://www.youtube.com/watch?v=XXXXXXXXXXX>
yt-dlpの更新
brew upgrade yt-dlp
✅ 実行中のyt-dlpを途中で終了する方法
Ctrl + C
