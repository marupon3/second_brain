# _手動で成人用量を入力

手動オーバーライド かんたん手順
これは何をする作業？
アプリは添付文書から成人の上限量を自動で読み取っています。でも、ラコサミドやペランパネルのような「少しずつ増やす薬（漸増薬）」や、貼り薬は、文章が複雑で自動では読み取れません。
そこで、あなたが添付文書を見て、数字を手で入力するのがこの作業です。難しいプログラミングは不要で、やることは2つだけです：
メモ帳でファイルに数字を書く
コマンドを1行実行する
全体の流れ（5ステップ）
①最新を取得 →
②ファイルをコピー → ③メモ帳で数字を記入 → ④コマンド1行 → ⑤アプリ再ビルド
ステップ①
最新のコードを取得する
PowerShell（青い画面）を開いて、PediaDoseのフォルダで以下を順に実行します。
cd
C:\...\PediaDose       ←
あなたのPediaDoseフォルダの場所に置き換え
git pull origin
claude/stoic-fermat-nulch5
cd server
💡 cd
は「フォルダを移動する」コマンドです。フォルダの場所が分からなければ、エクスプローラーでPediaDoseフォルダを開き、アドレスバーのパスをコピーして貼り付けてください。
ステップ② 記入用ファイルを作る
ひな形ファイルをコピーして、自分用のファイルを作ります。
copy
data\adult_dose_overrides.example.json data\adult_dose_overrides.json
これで data\adult_dose_overrides.json
という記入用ファイルができました。
ステップ③
メモ帳で数字を記入する（いちばん大事）
ファイルをメモ帳で開きます。
notepad data\adult_dose_overrides.json
開くと、こんな内容が見えます（最初の方の
_readme は説明文なので無視してOK）：
"overrides": [
{
"match": {
"generic_name": "ラモトリギン" },
"adult_max_per_dose": null,
"adult_max_per_day": null,
"note":
"例）漸増薬。維持量の上限を..."
},
記入のしかた
null
と書いてある部分を、添付文書で確認した数字に書き換えるだけです。
項目        意味        書き方
adult_max_per_dose        成人の1回の上限（mg）        200
のように数字
adult_max_per_day        成人の1日の上限（mg）        400
のように数字
note        根拠メモ（添付文書の版など）        "2024年改訂で確認"
記入例（※数字は仮です。必ず添付文書で確認してください）：
{
"match": {
"generic_name": "ラモトリギン" },
"adult_max_per_dose": 200,
"adult_max_per_day": 400,
"note":
"添付文書2024年12月改訂で確認"
},
守ってほしいルール（3つ）
数字には
"（引用符）をつけない → 200 はOK、"200" はダメ
行末のカンマ , は消さない →
形が崩れるとエラーになります
g（グラム）の薬は ×1000
して mg にする → 例：2g なら 2000
💡 1回量しか分からない薬は adult_max_per_dose
だけ書いて、adult_max_per_day は null のままでOK。逆も同じ。両方 null のままだと、その薬は無視されます（安全のため）。
書き終わったら
上書き保存（Ctrl+S）して閉じます。
今回あなたが記入すべき薬（CSVの「要調査」11件）
一般名        メモ
ラモトリギン        漸増薬。維持量の上限を確認
ペランパネル水和物        漸増薬
ラコサミド        漸増薬
ジクロフェナクナトリウム（テープ・パップ）        貼り薬。mg比較が無意味なら記入しない（項目ごと削除でOK）
テリパラチド酢酸塩 /
スキサメトニウム        mg以外の単位。比較対象外なら記入不要
ひな形には最初の3つ（抗てんかん薬）が入っています。他の薬を追加したいときは、既存のブロックをまるごとコピペして
generic_name と数字を変えてください。
💡
generic_name（一般名）で指定すると、同じ成分の全メーカー品にまとめて反映されます（「アメル」「サワイ」など個別に書かなくてOK）。
ステップ④
コマンド1行で反映する
python tools/apply_adult_overrides.py
実行すると、こんな表示が出れば成功です：
+ ラモトリギン錠「アメル」: 成人量 1回200mg／1日400mg（手動）
+ ラモトリギン錠「サワイ」: 成人量 1回200mg／1日400mg（手動）
完了: ○薬剤を更新
「一致なし」と出たら、generic_name
の文字が添付文書の表記と違っている可能性があります（CSVの「一般名」列をコピペすると確実です）。
ステップ⑤ アプリを再ビルドする
いつものビルド手順を実行すれば、手入力した成人用量が端末アプリに反映されます。
安心ポイント
手で入れた値には「手動」の印がつき、次回以降の自動取得（backfill）で勝手に上書きされません。あなたの確認した値が守られます。
間違えても、ステップ③でファイルを直して④を再実行すれば、何度でも上書きできます。
確認後の残りは python
tools/list_missing_adult.py でいつでもチェックできます。
どの薬から記入するか迷ったら、まず
ラコサミド・ペランパネル・ラモトリギン（漸増抗てんかん薬）
の3つから始めるのがおすすめです。実際に1件記入してみて詰まったら、その箇所を貼ってもらえれば一緒に直します。
