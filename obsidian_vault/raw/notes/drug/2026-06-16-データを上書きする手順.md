# _データを上書きする手順

データを更新するときは、手動オーバーライドを必ず最後にしてください。
python
tools/prefetch_pmda.py          # ①
PMDA再取得（最初）
python
tools/revalidate_doses.py        # ②
既存データの誤ルール除去
python
tools/backfill_adult_dose.py     # ③
成人量の自動補完（あれば）
python
tools/apply_adult_overrides.py   # ④
手動の成人量（必ず最後に再適用）
# ⑤ APK 再ビルド
この順番なら、①で一部が上書きされても④で必ず上書き直されるので、手動値が常に最終的に反映されます。
