# VBA, Excelで0埋め

0埋め
Function
ZeroPadString(Text As String, Length As Integer) As String
ZeroPadString = Right(String(Length,
"0") & Text, Length)
End Function
第一引数にゼロ埋めしたい文字列
第二引数にはゼロ埋め後の総桁数を指定
関数の呼び込み方

Sub
ExampleUsageString()
Dim paddedString As String
paddedString = ZeroPadString("abc", 5)
Debug.Print paddedString  ' 出力: 00abc
End Sub
