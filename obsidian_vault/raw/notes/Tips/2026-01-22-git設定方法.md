# git設定方法

## Git でフォルダ階層を丸ごと履歴管理する手順

1. 管理したいフォルダに移動する
例として、管理したいフォルダが C:\project だとする。
cd C:\project
2. Git リポジトリを初期化する
このフォルダを Git
管理下に置く。
git init
これで
フォルダ全体（サブフォルダ・孫フォルダ含む）を一元管理できる状態 になる。
3. まずは現在のファイルを Git に登録する
git add .
は「このフォルダ以下すべて」という意味。
サブフォルダ・孫フォルダのファイルも全部対象になる。
4. 初回コミットを作成する
git commit -m "Initial commit"
これで「現時点のスナップショット」が履歴として保存される。

🔄 以降の更新管理
変更を確認する
git status
変更をステージングする
git add .
コミットする
git commit -m "変更内容の説明"
🧭 よくある質問
Q.
サブフォルダや孫フォルダを個別に設定する必要はある？
→ 不要。
Git は「ルートフォルダを
init した時点で、その配下すべてを自動で管理」する。
Q.
除外したいファイルやフォルダがある場合は？
→  を作成して指定する。

*.log
