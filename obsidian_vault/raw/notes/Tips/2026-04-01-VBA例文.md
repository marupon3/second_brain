# VBA例文

① 国内サイト（日本語・実務向け）
1. エクセルの神髄
<https://excel-ubara.com/>
+ 業務レベルのマクロが多い
+ ファイル操作・帳票生成など長めのコード多数
2. Office TANAKA
<https://officetanaka.net/>
+ VBA界では定番
+ 実用サンプルが多く、10行以上のコードが基本
3. エクセルVBA入門
<https://www.vba100.com/>
+ サンプルが体系化されている
+ 実用的な処理単位でコードが長め
4. Excel VBA Tips
<https://excelvba.work/>
+ ファイル操作・データ処理系が豊富
+ まとまった処理単位のコードが多い
5. 侍エンジニア VBA記事
<https://www.sejuku.net/blog/category/vba/>
+ 解説＋まとまったコード
+ 初級〜中級で実用レベル
② 海外サイト（コード量が多く実践向け）
1. Excel Easy
<https://www.excel-easy.com/vba.html>
+ シンプルだが例題はまとまった処理単位
+ ループ・条件・配列など複合例あり
2. Contextures
<https://www.contextures.com/excelvba.html>
+ 実務系（データ整形・フォーム）
+ 10行以上の実用コード多数
3. Spreadsheet Guru
<https://www.thespreadsheetguru.com/>
+ 高品質な実務マクロ
+ かなり長いコード例が多い
4. Automate Excel
<https://www.automateexcel.com/vba/>
+ 実用コード＋解説
+ 配列・辞書・ファイル操作など本格的
5. WallStreetMojo
<https://www.wallstreetmojo.com/vba-examples/>
+ ビジネス用途のマクロが中心
+ 複数処理を組み合わせた長めのコードが多い
