# AI検索エンジンの検索コマンド集（Genspark・Perplexity）

Genspark（<https://www.genspark.ai/>）・Perplexityで使える検索演算子。従来の検索エンジン同様のフィルタ構文が利用可能。

| コマンド | 用途 | 例 |
| --- | --- | --- |
| `filetype:pdf` / `filetype:docx` / `filetype:xlsx` | ファイル形式を限定 | `filetype:pdf 気候変動レポート` |
| `site:example.com` | 特定サイト内を検索 | `site:reddit.com ChatGPT` |
| `before:YYYY-MM-DD` / `after:YYYY-MM-DD` | 日付範囲を指定 | `before:2023-01-01 スマートフォン市場` |
| `lang:en` / `lang:ja` | 言語を限定 | `lang:en Japanese cuisine` |
| `-keyword` | 特定キーワードを除外 | `-advertisement` |
| `"exact phrase"` | 完全一致フレーズ検索 | `"machine learning algorithms"` |
| `intitle:keyword` | タイトルにキーワードを含むページ | `intitle:AI` |
| `inurl:keyword` | URLにキーワードを含むページ | `inurl:AI` |

Perplexityでは`/`をコマンドの先頭に付けて使用する（例: `/filetype:pdf`、`/site:x.com`）。

## Felo・Genspark・Perplexityの参照情報数比較

同じ3つの質問（環境問題、歴史・事実確認、リアルタイムニュース）を投げ、各ツールが参照した情報件数を比較した検証（初期設定のまま検証）。

| 質問 | Felo | Genspark | Perplexity |
| --- | --- | --- | --- |
| 地球温暖化の影響とは？ | 18件 | 26件 | 8件 |
| ビットコインが最初に取引されたのは？ | 20件 | 28件 | 8件 |
| 2025年1月のトラック転落事故について | 11件 | 35件 | 12件 |

どの質問でもGensparkが最も多くの情報を参照し、Feloがそれに次ぐ。Perplexityは参照数こそ少ないが、すべての回答に情報源が付記され信憑性確認がしやすい。参照数の多さ＝質の高さとは限らない点に留意。

**各ツールの特徴**:
- **Felo**: SNS投稿からのリアルタイム情報収集と、研究論文等の専門情報の両方に対応
- **Genspark**: 検索結果をマインドマップ化して視覚的に整理、検索履歴を学習してパーソナライズ
- **Perplexity**: 信頼性の高い情報を優先し、すべての回答に情報源を付記。複数の最先端モデルから選択可能
