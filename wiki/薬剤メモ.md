# 薬剤メモ

`obsidian_vault/raw/figures/`配下の鮮明な画像（"Exported image ..."）を一次情報として構成したページ。それでも要点整理であり、臨床判断には必ず添付文書・インタビューフォーム等の一次情報を確認すること。

## 帯状疱疹治療薬（アシクロビル vs バラシクロビル）

| 項目 | アシクロビル（ゾビラックス） | バラシクロビル（バルトレックス） |
| --- | --- | --- |
| 吸収率 | 10〜20% | 約70% |
| 用法（成人帯状疱疹治療） | 1日5回 | 1日3回 |
| 特徴 | 吸収されにくいのが課題 | バリン（アミノ酸）をエステル化しペプチドトランスポーターを経由することで吸収効率が改善したプロドラッグ |

バラシクロビルはアシクロビルのプロドラッグで、体内でエステル加水分解されアシクロビルに変換される。吸収率の高さから服用回数を1日3回に減らせる。

## 経口抗血小板薬の代表例

| 薬剤（商品名） | 分類 | 主な特徴 | 主な注意点 |
| --- | --- | --- | --- |
| アスピリン（バイアスピリン） | COX阻害薬 | 最も処方量が多い抗血小板薬。川崎病にも適応 | COX阻害による消化性潰瘍・腎障害・アスピリン喘息に注意 |
| クロピドグレル（プラビックス） | ADP受容体遮断薬 | アスピリンより出血リスクが低く、COXを阻害しない | 遺伝子多型により作用に個人差が出る可能性 |
| プラスグレル（エフィエント） | ADP受容体遮断薬 | クロピドグレルの改良版、作用の個人差が少ない | クロピドグレルよりも出血リスクが高い報告あり |
| シロスタゾール（プレタール） | PDE阻害薬 | 血管拡張作用を持ち慢性動脈閉塞症に適応 | 頭痛・動悸・頻脈等の副作用。うっ血性心不全には禁忌 |

PCI後のステント血栓症予防や脳梗塞急性期では、アスピリンとプラスグレル等の2剤併用療法（DAPT）が行われる。プラスグレル以外ではクロピドグレル、チカグレロル（商品名: ブリリンタ）が併用されることもある。

## 2型糖尿病治療薬選択のアルゴリズム（第2版, 6ステップ）

1. **インスリン適応の判断**: 絶対的適応（インスリン依存状態、高血糖性の昏睡、重症の肝障害・腎障害、糖尿病合併妊娠、静脈栄養時、重症感染症、外傷、中等度の外科手術）と相対的適応（著明な高血糖、ステロイド治療時、糖毒性解除など）を判断
2. **目標HbA1c値の決定**: 65歳未満は原則7%未満、65歳以上はADL・認知機能・併存症・使用薬剤により7〜8.5%（インスリン・SU薬・グリニド薬使用時は下限値あり）
3. **病態（肥満の有無）に応じた薬剤選択**: 非肥満はピオグリタゾン・マンジャロを除く8種類から、肥満はSU薬・グリニド薬を除く8種類から選択
4. **安全性への配慮**: 低血糖リスクが高い場合はSU・グリニドを避ける、腎機能低下時はメトホルミン・SU・ナテグリニド・ピオグリタゾンを避ける、心不全ではピオグリタゾン・メトホルミンを避ける
5. **付加価値を考慮すべき併存疾患**: CKD（アルブミン尿）は1st SGLT2阻害薬・2nd GLP-1 RA、CKD（非アルブミン尿）はSGLT2阻害薬 or GLP-1 RA、心不全はSGLT2阻害薬、心血管疾患は1st SGLT2阻害薬・2nd GLP-1 RA
6. **考慮すべき患者背景**: 服薬継続率が高いのはDPP-4阻害薬、低いのはグリニド・α-GI。コストが高いのはGLP-1 RA・マンジャロ、低いのはメトホルミン・SU・ピオグリタゾン

## 透析患者における経口血糖降下薬

| 分類 | 使用可否・注意点 |
| --- | --- |
| DPP-4阻害薬 | DPP-4阻害薬から開始し血糖コントロール不十分なら追加検討。トラゼンタ・テネリアは用量調整不要 |
| αグルコシダーゼ阻害薬 | 透析患者で使用可能な唯一のインスリン分泌非促進系薬。全てのαGI薬が使用可能 |
| グリニド薬 | ナテグリニドは使用禁忌。ミチグリニド・レパグリニドは使用可能だが低用量から開始し低血糖に注意 |
| リベルサス（GLP-1経口薬） | 減量・用量調整不要で使用可能だが、透析患者への使用経験が少なく慎重投与 |

**投与が推奨されない、または禁忌の薬**: SU薬（活性代謝産物が腎排泄のため禁忌）、SGLT2阻害薬（血糖降下作用を期待できない）、ビグアナイド薬（乳酸アシドーシスリスクのため禁忌）、ピオグリタゾン（体液貯留リスクにより日本では投与禁忌）、ツイミーグ（十分なデータがなく推奨されない）。

## 高齢者で特に慎重な投与を要する糖尿病治療薬（高齢者の安全な薬物療法ガイドライン2025）

1. SU薬のなかでもグリベンクラミド・グリメピリドは使用を控える（使用するならグリクラジドが低血糖有意に少ない）
2. 高齢者でもメトホルミンは安全に使用可（乳酸アシドーシス予防のため腎機能を定期評価し用量調整）
3. ピオグリタゾンは心不全既往では使用しない（心不全のない患者でも骨折・特に女性・心不全リスクを上げるため少量から開始）
4. SGLT2阻害薬は心血管疾患・心不全・慢性腎臓病があれば利益あり（脱水・性器感染症・ケトアシドーシスに注意）
5. GLP-1受容体作動薬は心血管・腎イベントのリスクを低減させる可能性（消化器症状・食欲不振・低栄養に注意）

## 便秘治療薬の作用機序比較

| 薬剤（商品名） | 一般名 | 作用機序 |
| --- | --- | --- |
| アミティーザ | ルビプロストン | Cl⁻チャネル(ClC-2)を介した水分分泌作用。Cl⁻が腸管内へ、Na⁺と水が腸管内腔へ移動 |
| リンゼス | リナクロチド | GC-C受容体刺激→cGMP増加による水分分泌作用に加え、求心性神経の痛覚過敏改善作用 |
| グーフィス | エロビキシバット | 胆汁酸トランスポーター阻害による胆汁酸を介した水分分泌＋腸管運動促進作用 |

### 便秘薬の効果発現時間（目安）

| 薬剤 | 効果発現までの時間 |
| --- | --- |
| モビコール配合内用剤 | 48時間 |
| アミティーザカプセル24μg | 23時間 |
| ピコスルファートNa・ラキソベロン | 7〜12時間 |
| 酸化マグネシウム（マグミット等）・センノシド（プルゼニド等） | 8〜10時間 |
| リンゼス0.25mg | 6時間 |
| グーフィス錠5mg | 5時間 |

リンゼス錠は吸湿するため服用直前に取り出す。モビコールは水に溶かして服用が基本で、服用しにくい場合はお茶・ヨーグルト飲料・オレンジジュース等との相性が良い（カフェイン飲料・スポーツドリンクは相性が悪い）。温かい飲み物に溶かす場合は30〜40℃まで冷ます。

## 心不全治療薬（カルベジロール vs ビソプロロール）

| 項目 | カルベジロール（アーチスト） | ビソプロロール（メインテート） |
| --- | --- | --- |
| 作用 | α1、β1、β2を遮断 | β1を選択的に遮断 |
| 血管への作用 | 血管拡張（α1遮断） | ほぼなし |
| 心臓への作用 | 心拍数低下（ビソプロロールほどは下げない→頻脈を緩やかに改善） | 心拍数低下（カルベジロールより強力、頻脈症状が強い場合に適する） |
| 気管支への作用 | 気管支収縮（β2遮断） | 作用は小さいがゼロではない |
| 気管支喘息患者への使用 | 症状悪化のおそれから禁忌 | β1選択性が高いため使用可能 |

## 分岐鎖アミノ酸製剤（BCAA）の違い

| 項目 | リーバクト配合顆粒 | アミノレバンEN配合散 |
| --- | --- | --- |
| 組成 | 分岐鎖アミノ酸のみ含有（16kcal/包） | 五大栄養素（糖質・アミノ酸・脂質・ビタミン・微量元素）を含有（210kcal/包） |
| 適応 | 食事が摂れている患者向け | 食事摂取が不十分でも効果を発揮 |

## その他

- **アドレナリン受容体の特徴**: α1受容体（血管、刺激時に血管収縮=昇圧、遮断時に血管拡張=降圧）、β1受容体（心臓、刺激時に心拍数上昇・心収縮力増強、遮断時に低下）、β2受容体（気管支、刺激時に気管支拡張・血管拡張、遮断時に気管支収縮・血管収縮）。カテコラミンはアドレナリン受容体を刺激する薬。この他ノルアドレナリン分泌抑制に関わるα2受容体、排尿筋や脂肪細胞に関わるβ3受容体がある
