# iPhone設定Tips（動作を軽くする）

Apple Intelligence関連のバックグラウンド処理を止めて古いデバイスの動作を軽くする設定集。

1. **Apple Intelligenceを完全オフ**: 設定 → Apple IntelligenceとSiri → すべてをオフ。写真・メッセージ・メールの継続スキャンによるバックグラウンド負荷を止める
2. **ビジュアルインテリジェンスを無効化**: 設定 → カメラ → ビジュアルインテリジェンスをオフ
3. **Siriと検索サジェストをオフ**: 設定 → Siriと検索 → 各アプリの「サジェスト」をオフ（バックグラウンドインデックス化を停止）
4. **モーションと透明度を減らす**: 設定 → アクセシビリティ → モーション →「モーションを減らす」、設定 → アクセシビリティ → ディスプレイとテキストサイズ →「透明度を減らす」
5. **ジャーナリング提案を停止**: 設定 → プライバシーとセキュリティ → 位置情報サービス → システムサービス →「ジャーナリング提案」をオフ
