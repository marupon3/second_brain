# 各種ツールメモ

単発で記録されたツール・アプリの覚え書き。関連の少ない小さなメモをまとめる。

## Memento Database（Android/iOS）

自由にデータベース構造を設計できるモバイルアプリ。無料版と有料プランの違いは[こちらの記事](https://romanovhiga.hateblo.jp/entry/2020/04/08/200144#無料版と有料プランの違い)を参照。

## Amazon裏技の隠しコマンド

Amazonサイトの隠しコマンド・裏技を紹介する記事。<https://radiolife.com/internet/amazon/45201/>

検索URLにパラメータを追記して絞り込む例（`obsidian_vault/raw/figures/`の画像より）。

| コマンド | 表示結果 |
| --- | --- |
| `&emi=AN1VRQENFRJN5` | マーケットプレイス出品を検索結果から除外 |
| `&sort=popularity-rank` | 人気の高い順に並び替え |
| `&sort=salesrank` | 売上の良い順に並び替え |
| `&sort=-salesrank` | 売り上げの悪い順に並び替え |
| `&sort=review-rank` | レビューが良い順に並べ替え |
| `&sort=-review-rank` | レビューの悪い順に並び替え |
| `&pct-off=50-` | 50%以上安い品を表示 |
| `&pct-off=-50` | 50%以上安い品を除外して表示 |
| `&pct-off=50-90` | 50から90%安い品を表示 |
| `&high-price=2000` | 2,000円以下の商品だけ表示 |
| `&low-price=100&high-price=2000` | 100円から2,000円の商品のみを表示 |
| `&sort=-price` | 価格の高い順に並び替え |
| `&sort=price` | 価格の安い順に並び替え |
| `&sort=releasedate` | 発売日の新しい順に並び替え |

## PayPayのATMチャージ手順

セブン銀行等のATMで「スマホで取引」→アプリの「チャージ」で金額入力後「ATMチャージ」アイコンを選択→ATMでアプリ表示のQRコードを読み取る（またはアプリに表示された番号をATMに入力）→ATMで入金し「確認」で完了。詳細は[PayPayヘルプ](https://paypay.ne.jp/help/c0087/)を参照。
