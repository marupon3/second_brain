# 質問力メモ（思考を前進させる10フレーズ）

1on1やコンサルティングの現場で使える、相手の思考を前進させる質問のフレーズ集。「思考の質＝向き合う問いの質」という考え方が核。逆に「なんで？」という詰問は相手を萎縮させ自己弁護モードにさせるため避けるべきとされる。

| フレーズ | 狙い |
| --- | --- |
| どうなってればいいと思う？ | ゴールの状態を定義し、不満をゴールに変える |
| 違いはなんだと思う？ | うまくいっている状態との差分を可視化する |
| 何が不足してるせいで悩んでる？ | 現在の努力不足でなく前段階の設計不足に気づかせる |
| 一つしかできないとしたら、どれからやる？ | 選択肢過多による停止を防ぎ優先順位を炙り出す |
| 逆に失敗するとしたら、何が起こりそう？ | 漠然とした不安を具体的で対策可能なリスクに変える |
| Aだとして、自分にアドバイスするとしたら？ | 未来の自分の視点に立たせ、自分の中の答えを引き出す |
| Aさんだとして、どう考えると思う？ | 立場を変えて視野を広げ、感情のノイズを減らす |
| 今、何を前提にして考えてる？ | 無意識の思い込み（前提）を掘り起こす |
| それって、解くべき問題？ | 頑張るべき悩みと捨てるべき悩みを分ける |
| 誰に相談したら解決できそう？ | 自分一人で抱えず適切な相談相手に接続させる |

良い質問は思考の足場であり、自分自身に問いかけることでも効果を発揮する。質問力が高い人は相手を詰めるのではなく、相手の中にある答えが自然に出てくるように問いを置く。
