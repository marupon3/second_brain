# Python基礎用語集

| 用語 | 説明 | 例 |
| --- | --- | --- |
| 変数 | データや値を一時的に保存するための入れ物 | - |
| データ型 | 変数に入るデータの種類 | 数値、文字列、リストなど |
| 整数（int） | 小数点のない数 | `5`、`100` |
| 浮動小数点（float） | 小数点を含む数 | `3.14`、`0.5` |
| 文字列（str） | 文字や文章を扱うデータ型 | `"Hello"`、`"Python"` |
| リスト | 複数のデータを一つにまとめるデータ型 | `[1, 2, 3]`、`["apple", "banana"]` |
| 辞書（dict） | キーと値をセットで管理するデータ型 | `{"name": "John", "age": 25}` |
| 関数 | 繰り返し使える処理のまとまり | `print()`で画面に表示 |
| 引数 | 関数に渡す値 | `print("Hello")`の`"Hello"` |
| 返り値 | 関数が処理した結果を返すこと | `len("apple")`は文字列の長さを返す |
| 条件分岐 | 「もし〜ならこうする」と条件によって処理を分ける仕組み | `if`文 |
| ループ | 同じ処理を繰り返す仕組み | `for`や`while` |
| モジュール | 便利な機能やコードをまとめたファイル | `math`モジュール（数学計算） |
| パッケージ | 複数のモジュールをまとめたもの | - |
| ライブラリ | 特定の目的に使えるたくさんのモジュールの集まり | NumPyやPandas |
| インポート | 他のファイルやモジュールをプログラムに読み込むこと | `import math` |
| コメント | コードに書き込む説明。プログラムには影響しない | `# これはコメント` |
| インデント | コードの階層を示すための空白。Pythonでは必須 | - |
| コードブロック | 複数行のコードをまとめて一つの処理として扱う部分 | インデントで作られる |
| エラー | プログラムの実行中に起こる問題 | 文法ミスや不正な値が原因で発生 |
| デバッグ | プログラムのエラーを見つけて修正する作業 | - |
