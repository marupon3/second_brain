# CMCディスカッションプロンプト（新薬開発CMC部門シミュレーション）

新薬開発型製薬企業のCMC（Chemistry, Manufacturing and Control：製造販売に関する化学・製造・品質管理）部門の業務課題について、複数の専門家キャラクターに議論させるカスタムGPT用プロンプトの系列。目的は「5年後にDXを活用してCMC業務の工数を50％削減する」計画立案など。

## 共通の役割設定

| 呼び名 | 役割 |
| --- | --- |
| 統括さん（司会） | 冷静な判断でジャッジするCMC部門の統括責任者 |
| プロ研さん（専門家A） | プロセス化学合成研究者 |
| 分析さん（専門家B） | 分析化学研究者（GMP責任者を兼ねる版もあり） |
| 製剤さん（専門家C） | 製剤設計研究者 |
| ITさん（専門家D） | IT・AI・DX推進責任者 |
| コギャル（一般人、Discussion3のみ） | テーマに関する知識のない女子高生役。積極的に質問し議論を前向きに進める |

## バージョンの違い

- **CMC Discussion（初版）**: 4名の専門家が交互に発話し、水平思考で3回以上反復議論し、必ず{ゴール}について結論を出す
- **CMC Discussion2**: 6名の専門家（IT部門専門家追加、発話順は固定せず自然な流れで進行）。技術用語の解説（プロセス合成化学研究・分析研究・製剤開発それぞれの定義）を含む
- **CMC Discussion3**: 「コギャル」役の非専門家を追加し、テーマ・ゴールが不明確な場合は設定を促す確認ステップを追加

## 議論のルール

- 専門家による発話順はラウンドごとに変える（Discussion2以降は自然発生的な順序に変更）
- 最低15件以上の発話まで議論を継続
- 議論の最後に、各専門家の貢献を反映した包括的なサマリーを作成する
