# VBAサンプルサイト集

## 国内サイト（日本語・実務向け）

| サイト | 特徴 |
| --- | --- |
| [エクセルの神髄](https://excel-ubara.com/) | 業務レベルのマクロが多い。ファイル操作・帳票生成など長めのコード |
| [Office TANAKA](https://officetanaka.net/) | VBA界の定番。実用サンプルが多く10行以上のコードが基本 |
| [エクセルVBA入門](https://www.vba100.com/) | サンプルが体系化され、実用的な処理単位でコードが長め |
| [Excel VBA Tips](https://excelvba.work/) | ファイル操作・データ処理系が豊富 |
| [侍エンジニア VBA記事](https://www.sejuku.net/blog/category/vba/) | 解説＋まとまったコード。初級〜中級で実用レベル |

## 海外サイト（コード量が多く実践向け）

| サイト | 特徴 |
| --- | --- |
| [Excel Easy](https://www.excel-easy.com/vba.html) | シンプルだがループ・条件・配列など複合例あり |
| [Contextures](https://www.contextures.com/excelvba.html) | 実務系（データ整形・フォーム）、10行以上の実用コード |
| [Spreadsheet Guru](https://www.thespreadsheetguru.com/) | 高品質な実務マクロ、長いコード例が多い |
| [Automate Excel](https://www.automateexcel.com/vba/) | 配列・辞書・ファイル操作など本格的な実用コード |
| [WallStreetMojo](https://www.wallstreetmojo.com/vba-examples/) | ビジネス用途のマクロ中心、複数処理を組み合わせた長めのコード |
