# 哲学史ノート

書籍「哲学入門」からの読書メモ。主要哲学者とその核心概念・引用を時代順に整理したもの。

## 第一章 ギリシア哲学からキリスト教哲学へ

| 哲学者 | 核心概念 |
| --- | --- |
| タレス | 万物の根源（アルケー）は水。神話的説明からロゴス（理性）による説明への転換 |
| ピタゴラス | 万物は数から成る |
| ヘラクレイトス | 万物は流転する |
| パルメニデス | 「あるものはあり、ないものはない」、変化の根底に不変のものがある |
| ゼノン | アキレスと亀のパラドックス。変化は錯覚であると主張 |
| プロタゴラス | 人間は万物の尺度である（相対主義、ソフィストの人間尺度論） |
| ソクラテス | 対話により普遍的・客観的真理を追求。無知の自覚から出発 |
| プラトン | イデア論。想起説（人間の学びは想起）。エロース（美を求める愛） |
| アリストテレス | イデアは事物に内在する形相。目的論的自然観。中庸の徳 |
| エピクロス | 快楽主義。心の平静（アタラクシア）を追求 |
| ゼノン（ストア派） | 理性（ロゴス）に従い情念を抑えた不動心（アパティア） |
| プロティノス | 世界は「一者」からの流出 |
| アウグスティヌス | 神への帰依と恩寵による救済 |
| アンセルムス | 理性のみによる神の存在論証 |
| トマス・アクィナス | 理性（自然の光）と信仰（恩寵の光）の調和 |

## 第二章 自我の独立と理性の哲学

| 哲学者 | 核心概念 |
| --- | --- |
| デカルト | 「我思う、ゆえに我あり」。物心二元論、機械論的自然観 |
| パスカル | 「人間は考える葦である」 |
| スピノザ | 幾何学的秩序による汎神論 |
| ライプニッツ | モナド論、予定調和 |
| ベーコン | 科学的法則の発見による自然のコントロール |
| ロック | タブラ・ラサ（白紙）説、経験論 |
| バークリ | 「存在するとは知覚されること」 |
| ヒューム | 因果律の否定、知覚の束としての自我 |
| カント | 批判哲学。認識論の革新（主観が現象を構成）。善なる意志の重視 |
| フィヒテ | 自我論の三段階、ヘーゲル弁証法への橋渡し |
| シェリング | 精神と物質を一原理に還元 |
| ヘーゲル | 弁証法。「理性的なものは現実的であり、現実的なものは理性的である」 |

## 第三章 内面を探求する哲学

| 哲学者 | 核心概念 |
| --- | --- |
| ショーペンハウアー | 盲目的意志の世界からの解脱 |
| ニーチェ | 力への意志、神は死んだ、ニヒリズムと運命愛 |
| キルケゴール | 主体的真理、単独者としての宗教的実存 |
| フッサール | 現象学的還元 |
| ハイデガー | 存在への問い、現存在、死への存在 |
| ヤスパース | 限界状況を通じた超越者との出会い |
| サルトル | 実存は本質に先立つ |
| メルロ・ポンティ | 身体を通じた知覚の現象学 |

## 第四章 社会改革と実践の哲学

| 哲学者 | 核心概念 |
| --- | --- |
| ベンサム | 量的功利主義、最大多数の最大幸福 |
| ミル | 質的功利主義（快楽の質を重視） |
| ジェイムズ | プラグマティズム（有用性としての真理） |
| デューイ | 道具主義、哲学の改造 |
| レヴィナス | 他者の顔、「汝、殺害を犯すことなかれ」 |
| マルクス | 世界の解釈でなく変革のための哲学 |
| アルチュセール | マルクス主義の理論的再構築 |

## 第五章 言語と知の哲学

| 哲学者 | 核心概念 |
| --- | --- |
| ソシュール | 言語記号論、言葉と世界の結びつき |
| ウィトゲンシュタイン | 「語りえぬものについては沈黙しなければならない」 |
| ムーア | 善は定義できない（直覚主義） |
| レヴィ＝ストロース | 構造主義、未開部族の思考の科学性 |
| フーコー | パノプティコンと権力、エピステーメーの時代的変化 |
| ドゥルーズ | 欲望する機械、連続する存在 |
| デリダ | エクリチュール（書かれた言葉）の自律性 |
