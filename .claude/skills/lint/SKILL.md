# lint

## When to use

- ユーザーが `/lint` を実行したとき
- Vaultの整合性・鮮度を定期的に確認したいとき

## When not to use

- `wiki/`にページが1件も無いとき

## Input

- `wiki/` `obsidian_vault/daily/` `weekly/` 配下の全Markdownファイル

## Output

- 検出結果のレポート（`wiki/log.md`への追記、および必要に応じて`wiki/lint-report.md`）

## 手順

1. 対象ファイル内の全wikilink（`[[ページ名]]`）を収集し、リンク先ページが実在するかを検証する。存在しないリンクを「リンク切れ」として記録する。
2. どのページからもリンクされていない`wiki/`配下のページを「孤立ページ」として記録する。
3. 同一トピックについて内容が相反する可能性のある記述を検出する。判断が難しい場合は断定せず、AIの所見として記録するに留める。
4. **陳腐化の検出**（下記「陳腐化の検出基準」に従う）。古くなった可能性のある記述を「要再確認」として記録する。**古い＝誤りではない**ため、断定せず候補として挙げるに留める。
5. 検出結果を一覧化し、`wiki/log.md`に追記する。件数が多い場合は`wiki/lint-report.md`に詳細を出力する。

## 陳腐化の検出基準

「いつの事実か」を問えない記憶は信頼できないため、以下の観点で古びた可能性のある記述を洗い出す。

1. **frontmatterの`updated:`の形式と鮮度**
   - `updated:`が無いページ、および`YYYY-MM-DD`形式（ISO 8601）でない値を持つページを報告する。
   - `updated:`が実行日から**90日以上前**のページを「棚卸し候補」として一覧化する。件数が多い場合は日付の古い順に上位20件までとする。
2. **実在しないパス・ファイルへの言及**
   - `wiki/`・`weekly/`・`obsidian_vault/daily/`の本文に登場するリポジトリ内パス（`docs/...`、`scripts/...`、`.claude/skills/...`、`obsidian_vault/...`等）を抽出し、実際に存在するかを検証する。存在しないものを「実体のない参照」として報告する。
   - 廃止済みのフォルダ名（`areas/`、`resources/`、`projects/`、`docs/`）への言及は特に見落とされやすいため、必ず確認する。
   - ただし**過去の経緯を意図的に記録している箇所**（`wiki/log.md`、[[session-archive|セッション作業アーカイブ]]、および「廃止済み」「削除した」と明記された文脈）は、履歴として正しいため対象外とする。
3. **`source:`が指す原文の消失**
   - frontmatterの`source:`に挙げられた`obsidian_vault/raw/`配下のファイルが実在するかを確認し、失われているものを報告する。同期による消失の早期発見を兼ねる。
4. **同一事実の重複記載**
   - 同じ事実が複数ページに書かれている箇所を検出する。片方だけが更新されて食い違う原因になるため、統合先の候補とともに報告する。

## 陳腐化の報告フォーマット

報告には必ず「何が」「いつ時点の記述か」「何を確認すれば判定できるか」を含める。

```
### 陳腐化の疑い

- `wiki/例.md`（updated: 2026-03-01、170日経過）
  - 記述: 「設定は docs/example.md を参照」
  - 疑い: `docs/example.md`が実在しない（実体のない参照）
  - 確認方法: 現在の参照先を特定し、記述を差し替えるか削除するかを判断する
```

## 制約

- **検出・報告のみとし、自動修正は行わない**（誤修正リスクを避けるため。`CLAUDE.md` 4節 禁止事項）。陳腐化の検出も同様に、報告のみとし記述の書き換え・削除は行わない。
- 修正はユーザー自身の判断に委ねる（手動修正、またはユーザーがClaudeへ個別に修正を指示する）。
- **古いことを誤りと断定しない。** `updated:`が古いだけのページは、内容が今も正しい場合がある。あくまで「再確認すべき候補」として報告する。
- `obsidian_vault/raw/`配下のファイルを編集しない。
- 出力は日本語で書く。
- ファイル入出力時はエンコーディングを UTF-8 で明示する。
- コンソール出力以外で絵文字を使わない。
