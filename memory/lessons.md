# 学び（一般化の途中）

`/lint` が繰り返し検出した違反のうち、**まだ「規約」として一文に言い切れていない
もの**を置く。規約との違いは、検証コードが対応しているかどうかではなく、
「守るべきルールとして確定したか」である。

- 確定したもの → `memory/conventions.md` へ移す
- 状況が変わって不要になったもの → 削除する

書き換えの経路は `memory/conventions.md` と同じ（`/dream` の提案を人間が承認するか、
人間が直接編集する）。
